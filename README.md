# Mô phỏng đóng hàng – Kairos Thermo DR-3 240L

Mô hình 3D xếp hàng (1 set = 1 bình + 2 tấm kính + 1 bộ chân) lên 5 loại xe 1,25T → 8T,
kèm đề xuất phương án an toàn / tối ưu utilization.

👉 Xem trực tiếp: trang GitHub Pages của repo này (Settings → Pages).

- Chọn loại xe, xoay/zoom mô hình, bấm "Xếp từng bước" để xem thứ tự đóng hàng.
- Số liệu: kích thước kiện & lòng thùng từ file dữ liệu Flat 3; trọng lượng bình 130 kg, kính 10 kg, chân 10 kg.
- Cập nhật: 19/11/2026.
